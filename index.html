CSS Scroll Bar

CSS Scrollbar Selectors

Chrome, Edge, Safari и Opera поддерживают нестандартный ::-webkit-scrollbar, который позволяет изменять внешний вид полосы прокрутки браузера.

Вы можете использовать следующие псевдоэлементы для настройки прокрутки:

✅ ::-webkit-scrollbar — вся полоса прокрутки.

✅ ::-webkit-scrollbar-thumb — перетаскиваемый маркер.

✅ ::-webkit-scrollbar-track — дорожка прокрутки.

✅ ::-webkit-scrollbar-button — кнопки прокрутки.

✅ ::-webkit-scrollbar-track-piece — часть дорожки.

✅ ::-webkit-scrollbar-corner — угол между полосами.

Зачем это нужно?

Кастомная полоса прокрутки помогает сделать сайт более стильным и индивидуальным.

Пример использования

Вы можете менять цвет, ширину и форму полосы прокрутки с помощью CSS.

Code:

body {
    --sb-track-color: #222;
    --sb-thumb-color: #ea7711;
    --sb-size: 1rem;
}

body::-webkit-scrollbar {
    width: var(--sb-size);
}

body::-webkit-scrollbar-track {
    background: var(--sb-track-color);
    border-radius: 1rem;
}

body::-webkit-scrollbar-thumb {
    background: var(--sb-thumb-color);
    border-radius: 1rem;
}

body {
    scrollbar-color: var(--sb-thumb-color)
                     var(--sb-track-color);
    scrollbar-width: thin;
}
